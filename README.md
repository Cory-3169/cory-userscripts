# cory-userscripts

Коллекция userscripts для [Tampermonkey](https://www.tampermonkey.net/) / Violentmonkey.
Все скрипты обновляются автоматически: Tampermonkey периодически проверяет `@updateURL` и подтягивает новую версию.

## Установка

1. Поставь [Tampermonkey](https://www.tampermonkey.net/).
2. Нажми «⬇️ Установить» напротив нужного скрипта — откроется окно установки.
3. Всё. Обновления прилетают сами (проверка по умолчанию — раз в сутки).

Принудительная проверка: **Tampermonkey → Dashboard → Utilities → Check for userscript updates**.

## Разработка

```
scripts/     *.user.js — публикуемые скрипты (+ сгенерированные *.meta.js)
templates/   заготовка для нового скрипта
.github/     workflow сборки
```

Новый скрипт:

1. Скопируй `templates/template.user.js` в `scripts/<имя>.user.js`.
2. Заполни `@name`, `@description`, `@match`.
3. `git push` в `main`.

GitHub Action при каждом пуше:

- подставляет `@downloadURL` / `@updateURL` / `@homepageURL` / `@supportURL` из имени репозитория;
- поднимает последний сегмент `@version`, если файл изменился, а версию не тронули руками;
- генерирует `*.meta.js` (лёгкий файл только с метаданными — по нему идёт проверка обновлений);
- пересобирает таблицу выше.

Хочешь выставить версию сам — просто поменяй `@version` в файле, автобамп это увидит и не тронет.

> ⚠️ Не меняй `@name` и `@namespace` после релиза: эта пара — идентификатор скрипта.
> Если изменить, у пользователей он станет «другим скриптом» и обновление не придёт.
